# Bookish Bliss

اعملي برنامج ANDROID يخليني اقدر اقرا الكتب بتاعتي بسهوله ويكون شكله حلو ويكون فيه كل الفيوتشرز اللي انا محتاجها 
عاوز اعمل برنامج لقرايه الكتب يكون ممتع وفيه فيوتشرز كتير احترافيه ويكون مريح وعاوز يبقي بعمل import للكتب من الجهاز يقوم يحفظها عنده في المكتبه بتاعته اديني برومت يعمله بكل الفيوتشرز اللي ممكن احبها او احتاجها
Act as an expert Full-Stack Developer and UI/UX Designer. I want to build a feature-rich, beautiful, and highly immersive E-Reader web/desktop application (using React, TypeScript, Tailwind CSS, and local storage / IndexedDB for offline persistence). 

The app should not just display text; it should make reading an absolute joy and an engaging habit. Please design and generate the complete architecture, components, and styling for the following advanced features:

1. Local Book Import & Library Management:
   - Drag-and-drop or file picker to import books from the local device (support PDF, EPUB, TXT, and Markdown).
   - Automatic metadata extraction (Cover image, Title, Author, File size, and format).
   - Custom bookshelf organization: categories, tags (e.g., "Currently Reading", "Finished", "Favorites"), and search/filter by title or author.
   - Reading progress tracker for each book (percentage completed, estimated time left to finish based on reading speed).

2. Immersive & Customizable Reading Experience:
   - Clean, distraction-free reading interface with customizable themes: Dark mode, Sepia/Warm mode, OLED Black, and Light mode.
   - Typography controls: Custom font families, adjustable font size, line height, letter spacing, and page margins.
   - Reading layouts: Paginated book view (flipping pages like a real book) vs. Infinite vertical scroll.
   - Auto-scroll feature with adjustable speed for hands-free reading.

3. Interactive Study & Annotation Tools:
   - Text highlighter with multiple colors (e.g., Yellow for ideas, Green for quotes, Pink for vocab).
   - Interactive notes and marginalia attached to highlights or specific pages.
   - Built-in dictionary lookup and instant translation on text selection.
   - Export highlights and notes as Markdown, PDF, or to clipboard for note-taking apps.

4. Gamification & Reading Motivation (The "Fun" Factor):
   - Daily reading streak tracker with visual achievements and badges (e.g., "Night Owl", "Bookworm").
   - Reading session timer (Pomodoro mode for deep reading) with ambient background sounds (e.g., rain, library hum, coffee shop, lo-fi beats).
   - Daily/Weekly reading goal setting with progress rings.

5. Smart & AI-Ready Features (Optional/Modular):
   - AI Summary or "Explain this paragraph" panel for complex books.
   - Text-to-Speech (TTS) integration to listen to the book while multitasking.

Please provide a modular project structure, key React components (especially the Reader view and Library view with IndexedDB storage handling), and gorgeous, smooth Tailwind CSS styling with Framer Motion animations for page transitions and UI interactions.
