# A fresh, youthful visual identity

## What will change
- Give the library, PDF reader, reading stats, and sign-in screen one bold, playful editorial look with a vivid but balanced palette, clearer type hierarchy, expressive accents, and more polished surfaces.
- Redesign library shelves, book covers, buttons, and reader controls through shared styling while keeping the existing reading atmosphere and page content legible.
- Preserve all books, accounts, progress, reader tools, and storage behavior; this is a visual-only redesign.

## Technical details
- Refresh semantic color tokens and shared CSS in `src/styles.css`; add only presentation classes to existing route markup where needed.
- Keep the existing components, routes, and data flows intact. Do not run browser checks or tests; the user will review the preview.
